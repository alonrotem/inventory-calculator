## Working rules
- Only modify files I explicitly name, or ask before touching others.
- Never run git commit, push, reset, or checkout without asking.
- Never run DB migrations or SQL against any database; propose them as files only.
- Keep changes minimal; no refactors or formatting changes outside the task.
- After changes, list every file modified and why.
- Run `npm run lint` and relevant tests before saying a task is done.
